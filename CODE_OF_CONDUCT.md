# Code of conduct

SteamBridge contributors and users must keep project spaces welcoming, constructive,
and focused on the software.

## Expected behavior

- Be respectful and assume good intent.
- Give actionable technical feedback.
- Respect privacy, licensing, platform rules, and responsible disclosure.
- Accept maintainer decisions about project scope and safety.

## Unacceptable behavior

Harassment, threats, discrimination, doxxing, spam, credential requests, malicious code,
and attempts to use this project for piracy or security bypasses are not permitted.

## Enforcement

Report conduct concerns privately to the repository owner through GitHub. The maintainer
may edit or remove content, close contributions, or restrict participation when needed.
Good-faith security research reported through [SECURITY.md](SECURITY.md) is welcome.
