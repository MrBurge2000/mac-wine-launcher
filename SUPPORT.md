# Support

Use [GitHub Issues](https://github.com/MrBurge2000/SteamBridge/issues) for reproducible
SteamBridge bugs and feature requests. Include the app version, macOS version, Mac model
and architecture, selected engine/renderer, and sanitized logs.

This project cannot provide support for Steam accounts, purchases, DRM bypasses,
anti-cheat bypasses, pirated content, or proprietary third-party injectors. Contact
Valve or the game publisher for account and entitlement problems.

For vulnerabilities, follow [SECURITY.md](SECURITY.md) instead of filing a public issue.
